הרשקופ שול – גרסה סטטית (עובדת בלי Claude)
=============================================

תוכן התיקייה
- index.html  – האתר
- site.json   – נתוני האתר (מוצרים, דפים, עלון, באנרים). אפשר לערוך אותו
- img/        – כל התמונות כקבצים נפרדים

העלאה ל-GitHub Pages
1. פותחים חשבון חינמי ב-github.com ויוצרים מאגר (Repository) חדש, למשל hershkop-shul (ציבורי).
2. בעמוד המאגר לוחצים Add file > Upload files וגוררים לשם את כל התוכן של התיקייה (index.html, site.json, התיקייה img והקובץ .nojekyll). לוחצים Commit changes.
3. נכנסים ל-Settings > Pages. ב-Source בוחרים Deploy from a branch, ענף main ותיקייה / (root), ולוחצים Save.
4. אחרי דקה-שתיים האתר זמין בכתובת https://שם-המשתמש.github.io/hershkop-shul/

הערות
- גרסה זו סטטית: אין בה מסך ניהול. כדי לשנות מוצרים או טקסטים עורכים את site.json (או שולחים אותי לעדכן) ומעלים מחדש.
- תמונה חדשה: מעלים אותה לתיקייה img ומוסיפים את שמה (בלי הסיומת .jpg) בשדה img של המוצר ב-site.json.
- הקובץ hershkop-shul-single-file.html הוא אותו אתר עם כל התמונות מוטמעות בתוכו (קובץ אחד כבד יותר).
